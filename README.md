# 3. Explicación del montaje del equipo

## Preparación de la zona de trabajo
Antes de comenzar el montaje:
- Se limpia la mesa de trabajo.
- Se preparan las herramientas necesarias.
- Se utiliza pulsera y alfombrilla antiestática para evitar daños por electricidad estática.



## Primer paso: instalación de la placa base
Se abre la caja del ordenador y se instala la placa base en el interior.



## Segundo paso: instalación de la CPU y refrigeración
- Se coloca el procesador en su zócalo correspondiente.
- Se aplica pasta térmica.
- Se instala el ventilador del procesador.



## Tercer paso: instalación de la memoria RAM
- Se abren las pestañas de los zócalos RAM.
- Se insertan correctamente los módulos de memoria.
- Se cierran las pestañas asegurando una correcta fijación.



## Cuarto paso: instalación de la fuente de alimentación
- Se instala la fuente de alimentación.
- Se conectan los cables principales a la placa base.



## Quinto paso: instalación del almacenamiento y tarjeta gráfica

### SSD
- Se instala el SSD en la ranura correspondiente.
- Se fija mediante tornillo.

### Tarjeta gráfica
- Se instala en el puerto PCIe x16.
- Se coloca correctamente sin forzar los conectores.



## Sexto paso: revisión final
- Se revisan todas las conexiones.
- Se cierra la caja.
- Se inicia el ordenador.
- Se accede a la BIOS/UEFI para comprobar que todos los componentes son detectados correctamente.



# 4. Mantenimiento básico del equipo

## Limpieza interna del equipo

### Herramientas utilizadas
- Paños húmedos.
- Brochas o pinceles.
- Pistola de aire comprimido.

### Procedimiento
1. Desconectar el equipo de la corriente.
2. Abrir la caja.
3. Limpiar el polvo interno.
4. Limpiar ventiladores y rejillas.
5. Cerrar la caja y limpiar el exterior.



## Revisión de ventilación y temperatura

### Ventilación
Se comprobará:
- El ruido de los ventiladores.
- La circulación del aire.
- Posibles obstrucciones por polvo.

### Temperatura
Se utilizarán programas como:
- **CrystalDisk**

Esto permitirá controlar la temperatura de los componentes y evitar sobrecalentamientos.



## Actualización de componentes
La organización del cableado y los componentes facilitará:
- Cambios de hardware.
- Sustitución de piezas.
- Ampliaciones futuras.



## Sustitución de piezas defectuosas
Antes de sustituir un componente:
- Se realizarán pruebas individuales.
- Se comprobará el funcionamiento desde BIOS.
- Se verificará el componente en otro equipo si es necesario.


## Copias de seguridad básicas
Se utilizarán:
- Discos duros externos.

Esto permitirá:
- Guardar información importante.
- Evitar pérdidas de datos.
- Mantener espacio libre en los SSD.
